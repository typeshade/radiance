`OrbitControls` from `@typeshade/radiance-addons` moves a camera about a target. Its names
follow three.js's OrbitControls.

```ts
import { OrbitControls } from '@typeshade/radiance-addons';

const controls = new OrbitControls(camera, canvas);
controls.target.set(0, 0.5, 0);
controls.update();
controls.saveState();

renderer.setAnimationLoop(async () => {
  controls.update(clock.getDelta());
  renderer.preview = controls.moving ? 4 : 1;
  await renderer.render(scene, camera);
});
```

## Input

| Input                                      | Move                                    |
| ------------------------------------------ | --------------------------------------- |
| Drag, or one finger                        | orbit about the target                  |
| Right drag, middle drag, or Shift and drag | pan: the target slides with the pointer |
| Wheel, or a trackpad pinch                 | dolly toward or away from the target    |
| Two fingers                                | dolly and pan together                  |
| Double-click, R or Home                    | back to the saved view                  |
| Arrow keys, with Shift to pan. + and -     | a step of each move                     |

A turn let go with speed keeps turning and slows down, as a turntable does, while
`enableDamping` is on.

## Limits

| Property                             | What it bounds                            |
| ------------------------------------ | ----------------------------------------- |
| `minDistance`, `maxDistance`         | the distance from the target              |
| `minPolarAngle`, `maxPolarAngle`     | the angle from straight up, in radians    |
| `minAzimuthAngle`, `maxAzimuthAngle` | the turn about +y, in radians             |
| `targetBounds`                       | a `Box3` the target stays in when panning |

The polar angle keeps a margin of 0.01 radian from each pole, so the view never flips. The azimuth
has no limit. The examples set only the distance, from 0.05 to 50 scene units, so a drag can
look at a scene from below, from the side and from behind, and a wheel turn can go inside the
Cornell box or far outside it.

## Events and state

- `update(dt)` advances a coasting turn, places the camera, and answers whether it moved.
- `moving` is true while a pointer is down, the turn coasts, or a wheel just turned.
- `start`, `change` and `end` fire through `addEventListener`.
- `saveState()` remembers the view. `reset()` returns to it. `dispose()` removes the listeners.
