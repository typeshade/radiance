**Decision 0011.36.** A prior fixes the scale between albedo and light. It holds the 99th percentile of the base colour's luminance at 0.9. A grey card that the user marks can replace it. The gates measure the base colour after a scale for each channel. Proposed: the prior by default. This is a default.
