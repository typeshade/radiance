**Decision 0011.10.** The gradient method is the compiler's reverse-mode `grad` (C1), pulled before 1.0. Hand-written backward kernels are an interim path only if C1 is late, at the cost that part 4 states. Proposed: compiler reverse mode. This asks the owner, because it sets the compiler's roadmap and the start of part 4.
